SoftCPS REC Simulator

Simulate building energy communities with PV, batteries, EVs, flexible appliances, local energy sharing and electrical limits. This research fork extends CityLearn; install it as softcpsrecsimulator and import it as citylearn.

Start with Installation and QuickStart. The User guides and validation directory points to the maintained configuration, KPI and validation references.
