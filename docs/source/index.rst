=====================
SoftCPS REC Simulator
=====================

Simulate building energy communities with PV, batteries, EVs, flexible appliances,
local energy sharing and electrical limits. This research fork extends CityLearn;
install it as ``softcpsrecsimulator`` and import it as ``citylearn``.

Start with :doc:`installation` and :doc:`quickstart`. The :doc:`guides` directory
points to the maintained configuration, KPI and validation references.
